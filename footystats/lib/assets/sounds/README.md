# Sounds

Add a referee whistle sound file here:

- **referee_whistle.mp3** – Played when the match clock enters stoppage time (pill turns red).

You can use a short referee-whistle effect from free sound sites (e.g. [Freesound](https://freesound.org), [Mixkit](https://mixkit.co/free-sound-effects/)) and save it as `referee_whistle.mp3` in this folder. If the file is missing, the app falls back to a system beep.
